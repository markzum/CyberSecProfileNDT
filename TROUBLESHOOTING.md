# 🔧 Устранение неполадок AR

## Проблема: Синий экран, камера не открывается

### Решение 1: Проверьте HTTPS
AR.js требует HTTPS для доступа к камере (кроме localhost).

**Для локального тестирования:**
```bash
# Используйте localhost вместо 127.0.0.1
http://localhost:3750/team-demo
```

**Для доступа с телефона:**
Используйте SSL:
```bash
./setup_ar.sh
# Выберите пункт 4 (Запуск с HTTPS)
```

### Решение 2: Проверьте консоль браузера

Откройте консоль (F12) и проверьте ошибки:

**Ошибка "Cannot set properties of undefined":**
- ✅ ИСПРАВЛЕНО: Скрипты A-Frame теперь в `<head>`
- Обновите страницу (Ctrl+F5)

**Ошибка "NotAllowedError":**
- Разрешите доступ к камере в браузере
- Проверьте настройки приватности

**Ошибка "NotFoundError":**
- Камера не подключена
- Используйте устройство с камерой

### Решение 3: Очистите кэш

```bash
# В браузере:
Ctrl+Shift+Del → Очистить кэш
```

### Решение 4: Проверьте совместимость браузера

✅ **Поддерживаются:**
- Chrome 79+ (Android)
- Safari 11+ (iOS)
- Firefox 68+ (Android)

❌ **Не поддерживаются:**
- Internet Explorer
- Старые версии браузеров
- Некоторые WebView

### Решение 5: Тестирование на настольном компьютере

Для быстрого тестирования без мобильного устройства:

1. Откройте маркер Hiro на втором мониторе или распечатайте:
   https://raw.githubusercontent.com/AR-js-org/AR.js/master/data/images/hiro.png

2. Используйте внешнюю веб-камеру

3. Откройте демо: http://localhost:3750/team-demo

## Проблема: Маркеры не распознаются

### Решение:
1. ✅ Убедитесь, что весь маркер в кадре
2. ✅ Держите камеру на расстоянии 20-40 см
3. ✅ Улучшите освещение
4. ✅ Избегайте бликов
5. ✅ Распечатайте маркер качественно (не размытый)

## Проблема: Низкая производительность

### Решение:
1. Закройте другие приложения
2. Используйте более мощное устройство
3. Уменьшите разрешение камеры в коде:
   ```javascript
   width: { ideal: 640 },
   height: { ideal: 480 }
   ```

## Проверка работоспособности

### Шаг 1: Проверьте загрузку A-Frame
Откройте консоль и выполните:
```javascript
console.log(AFRAME.version)
```
Должна показать версию (например, "1.4.2")

### Шаг 2: Проверьте AR.js
```javascript
console.log(typeof THREEx !== 'undefined')
```
Должно быть `true`

### Шаг 3: Проверьте доступ к камере
```javascript
navigator.mediaDevices.getUserMedia({ video: true })
  .then(stream => console.log('✓ Камера доступна'))
  .catch(err => console.error('✗ Ошибка:', err))
```

## Быстрая диагностика

Запустите в консоли браузера:
```javascript
console.log({
  'A-Frame': typeof AFRAME !== 'undefined' ? AFRAME.version : '❌ Не загружен',
  'AR.js': typeof THREEx !== 'undefined' ? '✓ Загружен' : '❌ Не загружен',
  'HTTPS': location.protocol === 'https:' ? '✓' : '❌ Требуется для камеры',
  'Камера API': 'mediaDevices' in navigator ? '✓' : '❌ Не поддерживается'
})
```
